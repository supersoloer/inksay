# 隐私与网络行为

本文描述公开桌面源码的当前实现。衍生发行或未来版本的行为需要另行确认。

## 本地保存

桌面配置、词典、替换规则、纠错建议、历史、统计、模型和按保留设置保存的录音位于本机应用数据目录。API Key 使用 macOS Keychain / Windows 系统凭据存储，与业务 JSON 分开。

应用不包含向 InkSay 开发者发送历史或录音的自动上传逻辑，也不包含 InkSay 账号和云同步系统。用户主动联系开发者时，邮件或第三方网站由对应应用和平台处理。

## 发送到模型服务的内容

| 功能 | 网络目的地 | 可能发送的内容 |
| --- | --- | --- |
| 云端语音识别 | 使用者配置的 ASR 服务 | 音频、模型、语言提示和识别词典；支持的长录音可能分段提交 |
| 文字整理、翻译、询问 | 使用者配置的文字模型服务 | 转写文字、处理规则、词典及可用的输入场景上下文 |
| 模型下载 | 代码指定的模型托管站点 | 常规下载请求，不上传本地历史或录音 |
| 连接测试 | 当前配置的模型服务 | 内置公开语音样本或测试文本，不使用个人历史录音 |

文字处理的场景上下文可包含前台应用名、窗口标题、网页地址、选中文字和光标附近文字。获取取决于系统权限和目标应用支持情况，代码按长度截断。需要保密的材料应使用符合要求的服务，或不启用云端文字处理。

本地 Whisper 仅保证语音识别在本机完成。若同时开启云端文字整理，识别后的文字和对应上下文仍会发送到该服务。

## 系统权限

麦克风用于录音；输入监控用于快捷键；辅助功能用于获取输入上下文、文字写入和纠错反馈。应用在用户发起录音时采集音频。

## 保留、备份与诊断

删除历史或清空页面不等于立即擦除恢复备份。有效数据的上一版 `.bak` 和损坏隔离文件可能继续存在。需要彻底移除本机数据时，应退出应用后删除独立数据目录，并移除对应系统凭据。路径和格式见 [DATA.md](DATA.md)。

日志主要记录会话、阶段、耗时、请求状态及请求 ID。历史本身包含转写文字和错误信息，录音包含声音；诊断或截图也可能包含应用、服务及个人内容。发送给维护者前请检查和脱敏。

配置模型服务的保留、训练及地域政策由该服务提供者决定，InkSay 的本地保存方式不替代其政策。
