# 模型配置

语音识别和文字处理是两项独立配置。识别服务将音频转换为文字；文字模型用于整理、翻译或询问。只使用听写时可以不配置文字模型。

## 云端识别

填写 API Key、模型和服务地址后保存，再运行设置中的连接测试。密钥绑定请求地址，切换到自定义地址时需要重新明确保存密钥。

| 接口协议 | 地址示例（未启用完整请求地址） | 请求路径 |
| --- | --- | --- |
| DashScope 同步识别 | `https://dashscope.aliyuncs.com/api/v1` | `/services/aigc/multimodal-generation/generation` |
| OpenAI 音频转写 | `https://api.openai.com/v1` | `/audio/transcriptions` |
| OpenAI 音频消息 | 服务提供者给出的兼容地址，例如百炼 `https://dashscope.aliyuncs.com/compatible-mode/v1` | `/chat/completions` |

启用“完整请求地址”后，填写包含请求路径的完整 URL，应用不再追加路径。不能把转写地址和音频消息协议混用。公网地址要求 HTTPS；本机服务可使用 loopback HTTP。

百炼默认模型 `qwen-audio-3.1-asr-flash` 使用 DashScope 同步协议。百炼音频消息方式需要该方式支持的模型，例如 `qwen3-asr-flash`。专属业务空间或其他地域的地址以服务提供者文档为准。

### 长录音

DashScope 的 `qwen-audio-3.1-asr-flash`、`qwen-audio-3.0-asr-flash` 和 `fun-asr-flash-2026-06-15` 对超限录音使用内置 FLAC 无损压缩；超过单段 5 分钟或编码后大小预算时，按临近上限的低音量位置分段。

各段音频连续且不重叠，依次识别。全部成功后合并 ASR 文字，再进行一次文字处理。任一段失败时不将部分结果当成完整转写。本地原录音不被压缩过程替换；是否保存仍由录音保留设置决定。

此行为不自动扩展到未知模型或协议，避免向服务发送其不支持的编码。桌面单次录音仍有 10 分钟保护上限。

## 本地 Whisper

在设置中切换到本地识别，选择并下载模型。模型保存在应用数据目录，与源码仓库分开。下载需要网络，识别在本机进行。

云端模式也使用本地 VAD 过滤无语音录音，因此会启动内置的 `whisper-server` 辅助进程；这不代表识别已切换到本地 Whisper。

## 文字处理

填写 OpenAI 兼容服务地址、文字模型名和独立 API Key。按应用支持的地址形式配置，不使用 ASR 模型名代替文字模型。

未配置时，听写直接保留 ASR 结果及本地确定性规则处理结果。文字整理失败时，听写保留识别文字并记录失败原因。翻译和询问依赖文字模型，失败时不能视为成功完成。

## 排查

- 无识别配置：检查当前后端、地址、协议、模型和已保存的 API Key。
- 401 / 403：检查密钥、地域、权限及额度。
- 404：检查完整地址开关、请求路径和模型是否匹配。
- 429 / 超时：检查额度、限流、网络及服务状态。
- 识别成功但未写入：检查辅助功能权限、焦点切换和目标输入框。历史记录保留实际阶段与错误。

不要把未脱敏的配置、历史或录音直接贴到公开 Issue。网络和数据说明见 [PRIVACY.md](PRIVACY.md)。
